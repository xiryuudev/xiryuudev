## 🚀 Proyek

* **xiryuubot:** bot WhatsApp serba bisa (Baileys) — modul kampus RAISING (jadwal, presensi, tugas, pengumuman), AI chat, dan downloader media. [Tautan ke proyek](https://github.com/xiryuudev/xiryuubot)
* **aibotchat:** bot WhatsApp yang terintegrasi dengan AI untuk berkomunikasi dan menggunakan function. [Tautan ke proyek](https://github.com/xiryuudev/aibotchat)
* **student-wabot:** bot WhatsApp untuk anak sekolahan. [Tautan ke proyek](https://github.com/xiryuudev/student-wabot)
* **anicli-indo:** menonton anime subtitle Indonesia menggunakan terminal. [Tautan ke proyek](https://github.com/xiryuudev/anicli-indo)
* **smartDaily:** aplikasi desktop pencatat aktivitas harian — Electron + React + TypeScript + SQLite. [Tautan ke proyek](https://github.com/xiryuudev/smartDaily)
* **ResepKu:** aplikasi desktop resep masakan — Next.js + Electron + SQLite. [Tautan ke proyek](https://github.com/xiryuudev/ResepKu)
* **do-a-barrel-roll-horizon:** port mod Do a Barrel Roll (kontrol pitch/yaw/roll saat elytra) ke Horizon native mixin, ditulis dalam Rust. [Tautan ke proyek](https://github.com/xiryuudev/do-a-barrel-roll-horizon)
